# 聖杯之路

Fate 題材的卡牌冒險：從 15 位從者選一位（依職階分組）（每位一套自己的牌與機制：投影劍、石化、毒、軍勢、使魔、架勢、連擊……），走兩章分岔地圖（戰鬥、精英、事件、商店、休息、寶箱），打各章魔王；留著令咒還能進隱藏關。寶具量表滿了放大招，令咒整局只有 3 劃。打贏精英會「靈基覺醒」、偶爾拿到奧義牌；強化卡片時三選一方向；開局選難度與命運；每局得聖晶石，解鎖英靈與命座。每個帳號各自存檔（換裝置也接得上）。
Google Apps Script 網頁遊戲；規則全在 `gas/Game.html`，跑在玩家的瀏覽器裡。細節見 `CLAUDE.md`。

- 測試：`bash check.sh`｜平衡：`node tools/sim.js`
- 舊版在 git 歷史：《命運停駐之夜》`3dfd6cd`、《東方航路》`a409b92`。
