# 封魔錄

東方仙俠的卡牌冒險：五位女修（蘇凌霜・劍修、顧青璃・符修、白辰・御獸、赤練・血修、阿朵・蠱師）各帶一套自己的牌與機制（飛劍、定身符、小白龍阿白、以血換力、蠱毒），走兩章分岔地圖（落霞山、鬼哭城：戰鬥、精英、事件、商店、休息、寶箱），打各章魔王；留著師門玉符還能闖九幽魔淵斬心魔。神通量表滿了放大招，玉符整局 3 枚。打贏精英會頓悟、偶爾拿到秘傳牌；強化卡片時三選一方向；開局選難度與機緣；五位角色、全部機緣一開始就全開放。戰鬥畫面是舞台：角色站左、敵人站右（先用皮影剪影，之後換立繪）。每個帳號各自存檔（換裝置也接得上）。
Google Apps Script 網頁遊戲；規則全在 `gas/Game.html`，跑在玩家的瀏覽器裡。角色與世界觀見 `docs/設定書.md`，開發細節見 `CLAUDE.md`。

- 測試：`bash check.sh`｜平衡：`node tools/sim.js`
