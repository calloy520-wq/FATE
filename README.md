# 封魔錄

東方仙俠的戰棋（照《機器人大戰》的玩法）：五位女修（蘇凌霜・劍修、顧青璃・符修、白辰・御獸、赤灼・酒修、阿朵・蠱師）一起出擊，十四關照小說主線，從落霞山一路打到九幽魔淵，封印魘。方格地圖上移動、交手（還手／招架／閃身、助攻、掩護、合擊、陣法），用心訣扭轉局面；關卡之間淬鍊、修為、功法、法寶一路累積，整個遊戲玩一輪。不強化也打得完，但要好好排陣（布陣、站在隊友旁邊、看敵人範圍）；強化了輕鬆很多。劇情是另外的小說模式（前情提要、五位女修的初遇與插曲、真結局與尾聲）。每個帳號各自存檔（換裝置也接得上）。
Google Apps Script 網頁遊戲；戰棋的規則與資料在 `gas/Srw.html`，跑在玩家的瀏覽器裡。角色與世界觀見 `docs/設定書.md`，戰鬥設計見 `docs/戰鬥設計.md`，開發細節見 `CLAUDE.md`。

- 測試：`bash check.sh`｜平衡：`N=20 node tools/srw_sim.js`
- 舊版在 git 歷史：《封魔錄》卡牌版 `e36c791`、《聖杯之路》（Fate 版）`71c2ef2`、《命運停駐之夜》`3dfd6cd`、《東方航路》`a409b92`。
