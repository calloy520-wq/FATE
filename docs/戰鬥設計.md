# 戰鬥設計：機戰式戰棋（2026-10-08 玩家定）

玩家要的：**戰鬥全部改成機器人大戰的玩法**。
- 方格地圖戰棋
- 五位女修一起出擊
- 關卡制，淬鍊與修為一路累積（2026-10-08 起放寬「不要局外成長」：戰役本身就是養成）

系統結構照機戰；名詞、招式、角色全部原創（紅線 5），不用機戰的指令名稱。

## 一關的流程

**整備**（淬鍊、修為、法寶）→ **出擊** → **地圖戰** → **結算**（靈石、經驗、悟道點、功勳）→ 下一關。

地圖戰的回合：
- **我方階段**：每人移動一次、行動一次（攻擊／心訣／待機），順序自己決定。
- **敵方階段**：敵人照 AI 行動。

勝負：
- 勝利條件每關寫明：全滅、擊破魔王、撐過 N 回合等。
- 敗北：五人全倒。
- 倒下的人這關退場，結算後回來（不會永久死亡）。

## 一次交手

攻擊方先選招式和目標，畫面上會先顯示預覽：
- 雙方的命中率、預計傷害、爆擊率
- 對方會怎麼回應

被打的一方選回應方式：
- **還手**：要有射程夠、用得出來的招式；用哪一招自己挑。
- **招架**：傷害 ×½。
- **閃身**：對方命中率減半。例如命中 70%，閃身後變成 35%。

出手順序：攻擊方先出手；被打的一方沒倒才還手。
- **助攻**：攻擊方旁邊的隊友接著補一招（被打的一方不能還手）。
- **掩護**：被打的一方旁邊的隊友替她挨這一下，自動招架。

## 公式（照機戰 30 的結構）

**命中**
- 基本命中 ＝ 命中 / 2 ＋ 準頭 ＋ 招式命中修正
- 基本迴避 ＝ 迴避 / 2 ＋ 輕身
- 最終命中 ＝（基本命中 − 基本迴避）× 目標體積修正 ＋ 目標格子的迴避修正 ＋ 心訣與功法 ＋ 連續被打修正，夾在 0～100
- 目標體積修正：小 ×0.8、中 ×1、大 ×1.2、巨 ×1.4
- 連續被打：同一個階段裡，每多被打一次，迴避 −5%（命中 +5）
- 閃身：命中率 ×½
- 洞明：命中 100%
- 踏影：閃過下一次交手

**傷害**
- 攻擊 ＝ 威力 ×（格鬥、射擊或靈力 ＋ 戰意）/ 200（近身招用格鬥；飛劍、銀針、弩箭用射擊；符、蠱、龍息、劍陣用靈力）
- 防禦 ＝ 護體 ×（防禦 ＋ 戰意）/ 200
- 傷害 ＝（攻擊 − 防禦），最少 10，再依序乘上：
  - 目標格子的防禦修正
  - 體積差：每差一級 ±5%，上下限 −10%～+15%
  - 爆擊 ×1.25
  - 破釜 ×2、孤注 ×2.2（開了就不爆擊）
  - 招架 ×½
  - 金身 ×¼

**爆擊率** ＝ 悟性差 ＋ 招式爆擊修正

**戰意**
| 情況 | 戰意 |
|---|---|
| 打中 | +1 |
| 閃過 | +1 |
| 挨打 | +1（被精英、魔王打 +2） |
| 擊破 | +4 |
| 隊友擊破 | 全隊 +1 |

戰意同時乘進攻擊和防禦；大招要戰意到門檻才能用。

**心力**：出擊時全滿，每個我方階段開始 +3（功法「調息」再 +5）。

## 功法（悟道點買；機戰的技能程式）

- 助攻 Lv1–3、掩護 Lv1–3：每個階段能幫幾次
- 背水 Lv1–5
- 好戰：攻擊時戰意多 +1
- 堅忍：挨打、閃過時戰意多 +1
- 鬥志 Lv1–3：出擊戰意 +5／級
- 破限 Lv1–2：戰意上限 +10／級
- 調息：心力回復 +5
- 精專：心訣消耗 −20%
- 後發先至：還手時先出手
- 游擊：攻擊完還能走剩下的腳程
- 看破：戰意 130 以上，命中、迴避、爆擊 +15
- 護身：戰意 130 以上，受到的傷害 −20%

悟道點也能直接加修為：每項 +2 要 10 點。
