# 《封魔錄》美術清單（用 Google Flow 做 2D 圖）

做好的圖上傳到 GitHub，我來去背、裁切、壓縮，接進遊戲。**先做第一批（6 張角色＋4 張背景）就能看到效果**，後面再慢慢補。

---

## 一、共通規則（每一張都照這個做）

1. **背景用純綠色**（綠幕）：我會把綠色去掉變透明。
   - 角色或怪物身上**有綠色**的（表格裡標 🟣 的），改用**純洋紅色背景**（#FF00FF）。
2. **全身入鏡**：頭到腳都要在畫面裡，四周留一點空白，不要被切掉。
3. **方向**：
   - **五位女修面向右邊**（她們站在畫面左邊，面對右邊的敵人）。
   - **敵人面向左邊**。
4. **比例**：角色 **9:16（直的）**；背景 **16:9（橫的）**。
5. **不要有地板、影子、文字、邊框、浮水印**。
6. **畫風要統一**：每一段提示詞的最後都接上下面這行「共通畫風」。
7. **檔名照表格**（英文小寫），PNG 或 JPG 都可以。
8. 一張不滿意就多生幾張挑最好的；同一位角色之後要多做表情或動作時，用 Flow 的「素材（Ingredients）」放第一張當參考，臉才會一樣。

**共通畫風**（貼在每段提示詞最後）：
```
anime illustration, 2.5D semi-realistic cel shading, Chinese xianxia fantasy, intricate costume details, dramatic rim lighting, high quality, clean lineart
```

**綠幕背景**（角色、怪物都要加）：
```
full body from head to feet, entire figure inside the frame with margin, isolated on a solid flat pure green background (#00FF00), no floor, no shadow, no text, no frame, no watermark
```
🟣 的那幾張把最後一段換成：
```
full body from head to feet, entire figure inside the frame with margin, isolated on a solid flat pure magenta background (#FF00FF), no floor, no shadow, no text, no frame, no watermark
```
