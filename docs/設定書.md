**魘**：百年前從地底醒來的東西。沒有形體，靠吃人心裡放不下的念頭（執念）長大；吃掉誰，就學得會誰的樣子、誰的聲音，也能佔住誰的身體。殺不死，只能封。妖魔跟著它出世，天下大亂。

**封印的經過**（只有白辰在場看見，世人不知道細節）：
1. 五大宗門——**劍**（雲隱劍宗）、**符**（玄真觀）、**龍**（靈獸山莊）、**卦**（天機閣）、**丹**（丹鼎宗）——派了很多人把魘逼進地底的**九幽魔淵**；打到後來才發現**人越多，魘越強**（吃一個學一個），大部分人撤了。
2. 淵前只留**五宗各一位最強的人**：劍主沈望舒（雲隱劍宗）、白辰（靈獸山莊）、玄真觀祖師、天機閣與丹鼎宗的高手。
3. 封印要靠玄真觀祖師的**鎮魂印**。祖師畫到一半**力竭倒下**，印沒畫完、封不住；天機閣、丹鼎宗兩位也戰死。（**不寫「缺一筆」當成人人知道的口號**；只有白辰、青璃知道這道印沒畫完。）
4. 劍主**讓魘吞了自己，拿自己的身體當籠子**把它關住——雲隱劍宗練的是一顆不動搖的劍心，魘吞得下她的身體，吞不掉她的心。
5. 白辰要留下來一起面對（「我不走。要撐，一起撐。」），劍主笑著說「阿辰，出去」，把她**推出門外**；被推出去的那一刻，白辰反手按住劍主心口，把**半身龍元**渡過去（龍元只是護人的力，沒有心思、沒有執念，魘吃不了它，所以不算「多一個人」——這層只寫在設定，劇情不解釋）。門縫合上前劍主還在笑、朝她擺擺手，門從裡面闔上。**沒有人丟下她**。因為被推開過，後來她抱住劍主就不放手、不給劍主推開她的機會（尾聲廊下那一抱）。
6. 半身龍元留在淵裡，白辰和阿白都縮成了孩子的模樣。

**世人知道的**：劍主把魘關在裡面，再也沒有出來——大家都以為劍主死了，雲隱劍宗替她立了衣冠塚。
**白辰知道的**：淵裡那半身龍元一直亮著、護著劍主，所以劍主還活著。她把真相告訴了祖師最後的弟子青璃，等青璃把那道印練成（印畫完整了，劍主就不用再當籠子）；**卻一直沒告訴凌霜**——說了，凌霜一定會提著劍去撞那扇門。凌霜曾在衣冠塚前問她「師父走的時候，疼不疼？」，她知道那個人還活著、魘正在她身體裡一口一口地啃，還是答了「不疼」——這一百年她只說過這一次謊。她也知道魘吃的是什麼：那個人撐得越久，就忘得越多。

**時間線**（所有劇情文字照這個走）
0. **魘的來歷**：南疆百蠱寨的禁地裡原本供著一隻黑罐子，罐裡封著魘，靠一窩吃魔氣的老蠱守著、餓著；老祖宗的規矩是誰也不准打開，寨裡也沒人知道裡面是什麼。**百年前天魔教偷走罐子，在地底打開**，魘就此出世。寨子離得太遠，從沒把中原的魘跟那隻罐子連在一起；直到今年入夏魔氣滲進南疆，那窩老蠱認出了味道（阿婆：「那東西是從我們這裡跑出去的」），阿朵才背上老蠱往北走。所以她進門有自己的理由（「從寨子裡跑出去的，寨子的人來收」）。分工：青璃的鎮魂印封住門，阿朵的老蠱把魘從劍主身上剝下來。
1. **百年前**：魘出世 → 封印（上面的經過）。凌霜那時已是劍宗最強的弟子，師父出發前把掌門的玉印交給她：「宗門交給妳，別跟來。」青璃是玄真觀年紀最小的弟子，祖師走前把鎮魂印一筆一筆教給她（「等妳夠強了再畫」）。
2. **這一百年**：凌霜當掌門，住落霞山頂的塔上，白天練劍、夜裡撫琴（塔窗朝著魔淵，撫琴時從不關窗）；白辰大多待在山莊，每隔幾年去玄真觀看青璃畫印，偶爾到落霞山腳聽琴；青璃天天畫那道印，每次畫到最後紙就燒成灰，笑一笑再鋪一張。五大宗門都還興盛。
3. **今年春天**：青璃第一次畫成（紙沒有燒）；之後又燒、又成，練到**夏末十張成九張**，才傳信給靈獸山莊。
4. **今年入夏**：魔氣順地脈滲進南疆，阿朵往北走，一個多月後到江南；在鎮口**一眼看穿騙子**、裝作猶豫想看他還有什麼把戲（鐲子裡藏著蠱），青璃衝出來拆穿騙子把她「救」下，阿朵從此跟著青璃。
5. **今年春天～夏末**：赤灼春天下山尋伴；**夏末**在落霞山下的村子跟凌霜**並肩斬妖**（一大群妖：凌霜護著村民放不出飛劍，赤灼一笑魅惑、一刀裂地顧住後面，凌霜聚滿飛劍一次落下），赤灼替孩子擋了一下受了傷，凌霜道謝、說「傷要上藥。劍宗有客房」，互報門派姓名；當晚在塔下聽琴，認定「就是她了」；之後住在劍宗客房一個月，白天看練劍、夜裡塔下聽琴；住到第七天赤灼喝多了，朝塔上喊「掌門，我喜歡妳」，凌霜沒回答、也沒關窗；雨夜凌霜把燈挪到窗邊讓光落在石階上；凌霜沒趕她，也沒請她上塔。
6. **中秋前幾天**：白辰到江南，親眼看青璃畫成一道；本來打算帶青璃上落霞山，當面跟凌霜說清楚。
7. **中秋**（故事開始）：紅月升起，白辰**忽然感覺不到那半身龍元**（劍主撐不住、魘佔了上風）；封印鬆動，妖魔佔了魔淵口上的長寧城（城裡的人連夜逃走，路上的人從此叫它鬼哭城；長寧是百年前那一仗打完、回來的人取的名字）。白辰請青璃畫**傳信符**寄給凌霜：「妳師父還活著。往魔淵去，路上會合。」凌霜天亮前提劍下山，赤灼已在山門口等著，跟上；白辰帶青璃、阿朵往北，在往鬼哭城的路上會合。只有五人去、最後只一人進門＝百年前的教訓。
8. **中秋之後的深秋**（大約一個月內）：第一章落霞山 → 第二章鬼哭城 → 九幽魔淵（入口在鬼哭城底下）；五枚玉符一起捏碎，**五個人一起進門**（2026-10-06 玩家定：百年前是五宗各一人，沒道理這次只派一個人；遊戲裡還是一個人打，劇情是五人合力）；青璃畫完那道印，劍主活著出來，龍元跟著她出來。

- **鎮妖司**（朝廷｜京城地底｜交過手：影衛統領）：朝廷設立、專管妖物與修士的衙門，影衛是它直屬的暗衛。封印鬆動之後，鎮妖司動作頻頻，卻始終不曾公開表態。有人懷疑，影衛早已被魔氣滲透。
- **鬼市**（江湖｜鬼哭城（從前的長寧城）地下，只在月黑時開｜尚未現身）：黑市，攤子擺在長寧城的地底，開了不知道多少年，城裡的人都裝作不知道。這裡什麼都買得到，代價卻常常不是錢。攤販個個戴著面具，分不清是人是鬼。
