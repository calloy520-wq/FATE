## 一、世界觀與主線（2026-10-02 大修）

**魘**：三百年前從地底醒來的東西。沒有形體，靠吃人心裡放不下的念頭（執念）長大；吃掉誰，就學得會誰的樣子。殺不死，只能封。妖魔跟著它出世，天下大亂。

**五脈封印**：五大宗門——**劍**（雲隱劍宗）、**符**（玄真觀）、**龍**（靈獸山莊）、**卦**（天機閣）、**丹**（丹鼎宗）——合力把魘逼進地底的**九幽魔淵**（2026-10-05 玩家改）。一開始去了很多人，打了才發現**人越多，魘越強**（吃一個學一個），所以大部分人撤退，只留下**五宗各一位最強的人**：劍主沈望舒（雲隱劍宗）、白辰（靈獸山莊）、玄真觀祖師、天機閣與丹鼎宗的高手。封印的核心是玄真觀祖師的**鎮魂印**——祖師畫到最後一筆時戰死；**印缺了一筆，封不住**；天機閣、丹鼎宗那兩位也戰死。最後雲隱劍宗的劍主**沈望舒**把白辰推出門外，喊「缺的那一筆，我來補。別進來——人越多，它越強。封！」，自己留在裡面、用自己補上那一筆，**門是她從裡面封上的**。**沒有人丟下她，是她自己把人推出去、自己封的**；白辰是五人裡唯一活著出來的（燒掉半身龍元，從此孩童模樣），心結是「那天她把我推出去，我就那樣走了」。這三百年各宗一直想救她，可一開門魘就會跑、進去的人越多它越強。魘在裡面學了最強的劍主，三百年來劍主在裡面跟魘搶自己的身體。五大宗門至今都還興盛，各守魔淵外的一角陣腳。

**劍鳴與道侶契**：三百年來每到夜裡，凌霜在落霞山頂的塔上撫琴，魔淵深處就有一聲劍鳴回應——那是師父還在的信號。白辰也有自己的聯繫：她和劍主結過道侶契，三百年來每晚都感覺得到另一頭還有心跳。

**今年中秋**：紅月升起，**劍鳴斷了**，道侶契也同時沒了動靜。封印跟著鬆動，逃出來的妖魔佔了鬼哭城。三百年前的教訓還在（人越多，魘越強），所以這次也只有五個人去、最後只有一人進門。五個人是這樣湊齊的（**不是天機閣卜卦點名**；「劍、符、龍、酒、蠱」只當事後天機閣卷宗裡的一句）：

- **劍**：蘇凌霜，劍主的關門弟子，十二歲那年看著魔淵的門在師父身後關上，從此守在落霞山頂的塔裡，每晚撫琴等師父的劍鳴。劍鳴斷了，她下山去看師父怎麼了。
- **符**：顧青璃，三百年來第一個畫得完整「鎮魂印」的人——只有她補得上祖師沒畫完的最後一筆，封印才不用再靠人在裡面撐。今年春天她第一次把整道印畫完，觀主寫信給白辰；中秋前白辰找到她的符攤，當面試過，她身邊那時已經跟著阿朵。
- **龍**：白辰，三百年前留在淵前的五人裡唯一活著出來的（被劍主推出門外）。當年燒掉半身龍元，從此是孩童模樣。這三百年她走遍各地找一個畫得完整鎮魂印的符修（印一完整，就不必再有人在裡面撐）；今年中秋前在江南找到青璃，中秋那一夜道侶契靜了，她帶著青璃與阿朵往北，在往鬼哭城的路上與凌霜、赤灼會合。
- **酒**：赤灼，合歡宗的酒修。路過落霞山，在塔下聽凌霜撫琴聽了一個月就喜歡上了；本來就在塔下，凌霜一下山，她就跟了上去——單純喜歡，想找她一起合修。
- **蠱**：阿朵，中秋前就因為寨裡的蠱對魔氣不安，自己離開百蠱寨，順著魔氣往北，路上先遇到了青璃，兩人一起走（所以她們最早熟）。蠱吃魔氣——鬼哭城與魔淵的魔氣濃得活人走不進去，路得靠她的蠱開。

**玉符**：丹鼎宗與玄真觀一同煉的師門玉符，每人一枚。危急時捏碎能保命；留到最後，它能打開魔淵的門。
**兩章通關**＝平定佔了鬼哭城（魔淵口上）的妖魔，封印暫時穩住；但魔淵深處的劍鳴還是沒有回來。**真結局**＝留著玉符進九幽魔淵。捏碎玉符，魔淵的門只開一人寬（人進得越多魘越強）：**玩家選的那位一個人進去，其他四人在門外鎮住陣腳**，青璃在門外備好鎮魂印，等裡面的人出來就補上最後一筆（青璃自己進去時，就在裡面補）。最深處等著的是**劍主的身體、劍主的劍，裡面是魘**——五個人見到的是同一個人，魘用劍主的嘴，對每個人說她最放不下的事。打散魘，青璃補上鎮魂印的最後一筆，封印第一次完整；劍主的身體終於又是她自己的。**劍主活下來了**（不然三百年來每晚的劍鳴說不通）：被接出門時虛弱得睜不開眼，白辰把她帶回靈獸山莊養著。之後可以考慮把她做成新角色。從此不必再有人留在裡面。

**時間線**（2026-10-05 玩家定；所有劇情文字照這個走）
1. **三百年前**：魘出世；五大宗門合力把它逼進九幽魔淵；去的人很多，發現人越多魘越強，大部分人撤退，淵前只留五宗各一位最強的（劍主沈望舒、白辰、玄真觀祖師、天機閣與丹鼎宗的高手）；祖師畫鎮魂印到最後一筆時戰死，天機閣、丹鼎宗的兩位也戰死；劍主把白辰推出門外，喊「別進來——人越多，它越強。封！」，自己留在裡面用自己補上那一筆，門從裡面封上。白辰那年約七百一十八歲，燒掉半身龍元，從此是孩童模樣；凌霜那年十二歲，在門外看著門在師父身後闔上。
2. **這三百年**：凌霜守在落霞山頂的塔上，每晚撫琴，魔淵深處回一聲劍鳴；白辰在靈獸山莊，每晚感覺得到道侶契另一頭的心跳；五大宗門都還興盛，各守一角陣腳。
3. **今年春天到中秋前**：春天，青璃第一次把鎮魂印畫完整，觀主寫信去北方給白辰（白辰居無定所，信從山莊轉出去，追了她一整個夏天，夏末才送到）；入夏，阿朵因為寨裡的蠱對魔氣不安，第一次離開百蠱寨往北走，在江南的小鎮差點被騙走手鐲，青璃替她出頭，從此她就跟著青璃；夏末，赤灼下山尋伴，路過落霞山，在塔下聽了一個月的琴；中秋前幾天，白辰趕到江南找到青璃。
4. **今年中秋**（故事開始）：紅月升起，劍鳴斷了，道侶契同時沒了動靜。凌霜下山去看師父怎麼了，赤灼跟上；白辰當時人在江南——她找了三百年的符修，今年春天才出現（青璃第一次畫完整鎮魂印，玄真觀觀主寫信給她），中秋前她找到青璃的符攤、當面試過（阿朵入夏就已經跟在青璃身邊）。道侶契一靜，她帶著青璃與阿朵往北，半個月後在往鬼哭城的大路上攔住了凌霜與赤灼。只有五人去、最後只一人進門＝三百年前的教訓。白辰今年一千零一十八歲。
5. **中秋之後的深秋**（大約一個月內）：第一章落霞山 → 第二章鬼哭城 → 九幽魔淵（入口在鬼哭城底下）；選的那位一個人進門，其他四人守陣腳；青璃補上最後一筆，劍主活著出來。白辰進入第一千零一十九年。
6. **封印之後**：白辰在門口接過劍主，帶回北方雪谷的靈獸山莊養傷；凌霜回落霞山，赤灼被請上了塔；青璃回玄真觀顧義塾，阿朵跟著她。那年冬天，義塾的屋頂修好了。
7. **共同尾聲＝隔年中秋**（劍鳴斷了整整一年之後）：四個人到靈獸山莊找白辰過中秋；劍主養了快一年，能扶著走幾步、坐著聽完一整晚的琴；白辰燒進封印的半身龍元，在鎮魂印補完之後這一年慢慢回到她身上，這個中秋她第一次以原本的樣子出現（見〈白辰・原本的樣子〉）；凌霜這次是在師父面前親手彈給她聽——故事從中秋開始，也在中秋收尾。

**人物關係**
- 凌霜跟白辰：白辰是劍主的道侶，算凌霜半個師娘；看著凌霜從十二歲長大，一直叫她「小丫頭」；她心裡欠凌霜一句對不起（當年五人裡只有她一個人出來）。
- 凌霜跟赤灼：赤灼喜歡凌霜、大大方方地追；凌霜心裡只有師父，對這種事又三百年沒碰過，不知道怎麼回——熱臉貼冷臉，但凌霜沒有趕她走。
- 赤灼跟白辰：赤灼會把走累的白辰背起來走（白辰嘴上說本座自己會走，手抓得很緊）。**是真心的，不是討好**（2026-10-05 玩家說「當成未來的岳母孝敬，感覺太功利」）：赤灼一路上聽說了白辰的事：三百年前五人裡只有她活著出來、是被自己的道侶推出門外的，三百年了還是這麼小的身子——她對比自己弱的人本來就會多照顧一些。白辰是凌霜的師娘這件事留在背景，不拿來當赤灼的動機，也不寫「岳母」（專屬事件「背一程」，id `inlaw`；尾聲裡赤灼斟酒時還是習慣給白辰換成溫過的甜酒）。
- 青璃的帳本：一路上幫每個人買東西都記帳，最後沒有一筆是花在自己身上。
- 阿朵跟青璃（第三對，**明著寫**，跟凌霜×赤灼一樣；2026-10-05 玩家說「可以不用那麼含蓄」）：阿朵對外人冷、對自己人黏，最黏青璃，誰問起來就大大方方說「那是她的人」；青璃嘴上嫌麻煩、什麼都記帳，帳本上的「銀線」是替阿朵買的，被說破會臉紅，但不否認、不抽手。
- 之後可以出的新角色：天機閣、丹鼎宗的傳人（卦、丹兩脈還沒登場）。

**真結局：同一個結局，五個視角**（玩家選誰，就從誰的眼睛看；全文在 `ENDINGS`／`EPILOGUE`）

不管玩誰，這些事都一樣（自洽）：進門的人把魘從劍主身體裡趕出來 → 劍主醒來 → 青璃補上鎮魂印的最後一筆（在門外，或她自己進去時在裡面）→ 劍主被帶出門，**白辰在門口接過她，帶回靈獸山莊養著** → 凌霜看著師父被接走，空著的手被**赤灼**牽走 → 青璃回去顧義塾、記她的帳，阿朵跟著她；阿朵在每個人包袱裡放一隻傳信蝴蝶，只有青璃的沒放 → 隔年中秋，五個人都到靈獸山莊找白辰過節（尾聲）。

**配對**：凌霜×赤灼、白辰×劍主（三百年前就是拜過天地的道侶——三百年前是劍主把白辰推出門外、自己留在裡面；凌霜是劍主的徒弟，白辰算半個師娘，所以叫她「小丫頭」）；青璃×阿朵（明著寫：事件「銀線」——帳本上的蝴蝶是阿朵畫的；結局裡阿朵撲進青璃懷裡、在師兄面前牽起她的手說「以後也跟著她」；阿朵給每個人放傳信蝴蝶，只有青璃的包袱沒放：用不著）。

- 凌霜「接師父回家」：魘用師父的嘴說「長這麼高了」「上面那些人，哪一個等過妳三百年？」——師父最後說的是「別進來」，那才是師父；劍只對著那團黑；師父醒來，「長這麼高了」這一次是她自己說的，「每天晚上的琴，我都有聽見」，靠在凌霜肩上跟著她哼完最後一句（琴留到隔年中秋，在山莊當面彈）；凌霜背她出門，白辰低聲說了句對不起；凌霜手空了，赤灼走過來牽住，手燙得她指尖發麻，她沒抽回來；回到落霞山那晚，她拎酒去塔下敲門、請赤灼上塔，兩人坐在窗邊說起等劍鳴與聽琴的一個月，凌霜握住赤灼的手，赤灼的手指扣上來；塔上的燈熄了，「三百年來，落霞山的夜裡，第一次傳來的不是琴聲。」（留白）
- 青璃「這張不賣」：魘開價，金山銀山、義塾蓋幾間都行；她真的算了很久，淵底的寒氣把硃砂凍硬了，她咬破指尖補上最後一筆——「這張符，是拿來保護人的。不賣」；出門被阿朵從背後抱住（「妳進去的時候，我一直在數」），蝴蝶落在帳本上；師兄翻帳本，指頭停在「銀線」，阿朵牽起她的手說「我是跟她回來的，以後也跟著她」，青璃臉紅、沒抽手；那年冬天義塾的屋頂修好了。
- 白辰「第一千零一十九年」：三百年前她是從這扇門被推出來的，這次自己走進去；魘說「那天我把妳推出去，妳就那樣走了。三百年，妳一次也沒有回來」——「那天妳把我推出去，我就那樣走了。這一次，換我進來」（這裡不用「本座」）；劍主醒來，道侶契另一頭的心跳回來了；劍主醒來說「阿辰，妳怎麼變這麼小」——「還不是因為妳」；接住劍主抬不起的手，握了很久；跟凌霜說「當年是我一個人出來的。對不起」（三百年前凌霜站在人群後面，個子才到她胸口），把劍主帶回山莊照顧；回山莊的路上她走得很慢，把小披肩蓋在劍主手上，心口有一點暖（龍元正在回來的伏筆）；路上劍主問「妳還會變回去嗎？」——「……要變大，也不是不行」，說完耳朵紅了、把臉轉開（孩童模樣：只是不好意思，不帶曖昧）。尾聲收這一句：原本的樣子靠到劍主耳邊說「現在，總不會再嫌我小了吧」，劍主說不出話、耳根紅了。

## 九、畫面：戰鬥舞台

- 戰鬥畫面上半部是**舞台**：背景照章換（落霞山的黃昏、鬼哭城的紅月、魔淵的黑暗），**你的角色站左邊、敵人站右邊**。
- 角色會**呼吸晃動**；出牌時衝上去揮擊，敵人被打中會閃白、往後退、噴出傷害數字；你受傷時角色閃紅；放神通時角色放大特寫＋橫幅。
- 敵人頭上是意圖（要打多少），腳下是血條；點敵人選目標。
- **圖還沒來之前**，每位角色和敵人先用程式畫的剪影（輪廓＋發光的眼睛與武器）頂著。
- **立繪插槽**：之後有了 2D 立繪（PNG，透明背景）或 3D 模型，換上去就會取代剪影。2D 的建議尺寸：角色 1024×1536、敵人 1024×1024。
